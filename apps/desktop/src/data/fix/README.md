# FIX dictionaries

Bundled FIX 4.2 and FIX 4.4 dictionaries used by the FIX message inspector.

- Source: `@boarteam/fix-dict-fix42@4.1.0` and `@boarteam/fix-dict-fix44@4.1.0`
- Upstream repository: https://github.com/boarteam/fix-protocol
- Pinned source commit: `008c7e78f91629bbda0000c3e13e10e153f46a06`
- Source files: `packages/fix-dict-fix42/src/dictionary.json` and
  `packages/fix-dict-fix44/src/dictionary.json`

The low-level dictionary structure originates from the QuickFIX FIX44.xml and
FIX Repository 2010 sources. Field, enum, and datatype descriptions originate
from the Apache-2.0 FIX Orchestra orchestration files. See the two
`THIRD-PARTY-NOTICES-fix*.txt` files and `LICENSE-APACHE-2.0.txt` in this
directory for the applicable notices and license.
